# Ninewood 项目长期记忆

## 产品模型：需求卡片 vs 服务卡片的语义缺口

- 用户明确指出现有卡片（如截图"成都租车自驾·日租/周租"）呈现的是**服务者/供给侧**视角，意图是宣传自身服务，而不是需求者发布需求。
- 当前数据模型中 `Demand` 是需求者提需求，没有独立的供给侧服务卡片（ServiceListing/ProviderService）模型。
- 若要让卡片正确承载服务者宣传服务的意图，需要引入供给侧实体，而不是让 `Demand` 语义超载。
- 状态：已识别缺口，待用户决策是否新增 ServiceListing 模型及其与 Demand/Order 的关系。
