### 纠错：实际落地视觉 = 浅色 macOS 风，非纯黑
- `client-react/src/index.css` 真实 tokens：`--bg-primary:#F5F5F7`（浅灰）、`--bg-secondary:#FFFFFF`、`--text-primary:#1D1D1F`、`--accent-color:#007AFF`（Apple Blue）。注释明确「macOS 系统色：浅灰工作区 + 单一蓝色强调」。
- 这与 **DESIGN.md frontmatter**（#F5F5F7 / #007AFF / Light system surfaces / macOS-inspired）**一致**；与 DESIGN.md **正文**（纯黑 #000 / 纯白 #FFF / #3388FF）**相反**。
- 亦即：frontmatter 是对的、已落地；正文「纯黑」是过时残留。之前 §2 把实际落地判为「纯黑白」是错的，特此纠正。
- PRODUCT.md「暗色为主但不暗黑」也与实际浅色不符。代码注释里也混着「纯黑打底」与「macOS 浅灰」两套说法，迁移浅色后没清干净。
- 风险点：新 AI 若信 DESIGN 正文去做深色会整体跑偏；应以 frontmatter + index.css 为准。
