## 2. 系统应用领域、解决问题、基本功能、类似系统与特点共性

**问：** 系统应用领域，解决什么问题，有哪些基本功能。有无类似系统？相比较有哪些特点和共性。用文字注意说明。

**答：**

一、应用领域  
服务对接：维修、设计、跑腿、技能互助等「非标、短时、需沟通」的个性化服务交易。  
社区集成：需求圈的存在使得需求可以在同一类人群里高效流转，举例：第七小学家长需求圈，杭州修车圈

二、解决什么问题  

1. 需求方难以及时找到可信、匹配的服务者；  
2. 紧急需求下抢单不公平、沟通时间不足；  
3. 交易缺乏担保，纠纷难举证；  
4. 服务发现效率低（不知道搜什么、标签难匹配）。

三、基本功能  
用户注册登录、发布需求、发现/搜索匹配、两段式接单、即时通讯、担保支付与订单管理、认证信用、兴趣圈子、市场分析、管理后台、AI 助手。

四、类似系统  
猪八戒、58同城、闲鱼、美团跑腿等。

五、相比特点与共性  
共性：需求方—服务方对接 + 在线沟通 + 交易闭环。  
特点：15分钟紧急窗口 + 5分钟沟通资格、两段式接单、效果导向验收 + 拒绝广告和推流 + 担保机制、地域圈子（县/市/省级）、桌面端 + AI 语义辅助。

一句话总结：  
九木是全国范围的生活服务对接平台，通过「需求圈」让同类人群内的非标服务高效流转，并以紧急时间窗口、两段式接单、担保验收和无广告推流的规则，解决找人难、抢单不公、交易不信任和服务发现低效四类问题。

## 3. 已有类似系统，用户为何还要用你的？有何特点创新？是否针对特定用户？

**问：** 已有类似系统或者平台，用户为啥还要用你的？有哪些特点或者创新型？你的系统针对特定用户？

（结合实地观察与论述：街道经济、美团充电宝、说服供应商入驻几乎不可能；转而人人互为供需；相对论坛、QQ群、微信群、校园墙的不足等。）

**答：**

1. 已有类似平台，用户为啥还要用你的？

现有平台多是固定供应商加平台推流广告，或纯社交群里偶发求助。实地观察后发现，自己都兑现不了帮供应商接到单，就更难说服线下商家入驻，这是典型的先有鸡还是先有蛋。九木的选择是：不做固定名义的供应商池，把每个人同时当作服务者和需求者，像校园墙那样有事就来、同类人互助，但把群聊和论坛接不住的事补上。一是有经济驱动与担保，不是空聊；二是拒绝广告刷屏和推流干扰；三是紧急窗口加沟通资格，解决时效与不公平抢单；四是需求圈把信任边界收窄在同类人群里，例如第七小学家长圈、杭州修车圈。用户来用，不是换一个美团或猪八戒，而是要一个可交易、可圈内信任、不靠刷屏获客的互助对接场。

2. 特点与创新点

相对论坛：论坛无经济驱动、难成事；九木用需求明码、担保验收和订单闭环补上。相对QQ群微信群：广告、掺水、陌生人难聊；九木去广告去推流，进圈后再对接，在平台内沟通。相对校园墙：附庸社交软件、无担保无时效、功能单一、闲时无人看；九木做成独立产品，用时间窗口和两段式接单、效果验收，以及圈子加发现让内容可持续可逛。相对大型撮合平台：强推流、强供应商侧；九木是人人互为供需，圈内优先，时间与信任规则显性化。概括说：社交互助的形态加交易平台的规则，专攻非标、短时、需沟通的服务对接。

3. 是否针对特定用户？

不完全锁死某一行业，但默认用户画像清晰：面向全国范围内、愿意短暂当服务者也当需求者的普通人，而不是只招驻点商户；强需求发生在同一类人群、同一地域或同一场景里，如家长圈、修车圈、校园式关系，圈子是撮合单元；痛点是有事要人帮、有空能帮人，不是刷娱乐，也不是靠广告获客的固定店商。对传统固定供应商不硬拉入驻，能自然进来就好，主战场是人与人的双向对接。

（压缩版，约300字以内，曾用于快速回复：）

已有类似平台，多为固定商家入驻、广告推流获客；现场观察也表明，平台自己难兑现需求对接，就更难说服商家入驻。九木因此转向：不做固定名义供应商，人人互为服务者与需求者。相对论坛/QQ微信群/校园墙，补上经济驱动、去广告、担保验收与时效规则（15分钟窗口、两段式接单），并用需求圈把同类人放在一起对接。面向有互助意愿的普通人，非驻点店商；场景如家长圈、修车圈等。

## 4. 平台盈利模式

**问：** 平台盈利模式？

**答：**

平台盈利模式（可直接发给导师）

主收入是交易成功后的平台服务费：普通需求按成交价约 5%，由需求方在结算时额外承担；平台做预充值托管，完成后把服务款划给服务者，服务费留作平台收入，不做复杂分账。

次要规则配套控风险，本身不是主打盈利：发布时预付最低报价作托管；冻结或撤回按规则部分扣减押金，用于抑制虚假需求与拖欠决策。

公益类需求抽成更高约 10%，设计上专用于圈子建设或交有关方面处理，平台不以公益抽成为目的。开发阶段用点数模拟币值，上线后再接真实支付。

概括：靠成功撮合抽成赚钱，不以广告推流为主；押金是风控，不是主营业务。

## 5. 系统安全和用户隐私？老人、学生？如何防止涉黄或被恶意利用？

**问：** 系统安全和用户隐私如何保障？特别是老人,学生。如何防止涉黄或者恶意着被利用？

**答（最终版）：**

安全方面：账号需手机号验证登录，注册时会走人机验证，关键操作走服务端校验；交易走平台托管与担保，避免私下转账脱管；实名与技能认证分级，信用分影响接单权限；争议可投诉处理。隐私方面：位置发布做模糊处理，绝对不暴露精准坐标；圈子内对接优先于全网“裸奔”；用户可撤回或关闭不需要的公开信息。开发阶段以点数模拟资金，正式上线再接合规支付通道。
对老人：产品面向桌面宽屏，流程尽量少跳转，重要金额由系统自动结算并展示明细，减少被话术忽悠私下付费；紧急窗口与沟通资格有明确时限，降低被长期纠缠的风险。
对学生与未成年人：注册采集出生日期，低龄账号拒绝注册，需监护人同意的情形按合规要求处理；校园类需求鼓励落在学校家长等同类圈，缩小陌生人接触面；不依赖广告推流，减少诱导点击。未成年人交易限额（包括单笔支付，单日和更长的时间段）
防涉黄与被恶意利用：需求标题与描述走敏感词与内容合规校验，可疑内容进人工复核，可冻结或下架；去广告去推流，降低刷黄引流套路；虚假或滥用需求会因冻结规则损失托管资金；举报投诉与信用降权挂钩；系统在正式发布任何字段之前先检查，发现涉黄涉赌涉诈等违法内容后会一律清退并配合监管留存必要日志。
概括说：身份与内容可控、资金托管、圈内信任、可举报可下架，对老人重「少操作少私下付」，对学生重「准入与场景收窄」。

## 6. 支付和资金监管？撮合成功后会不会被交易者抛弃、无法获取收益？

**问：** 支付和资金监管？是否存在撮合成功后，会被交易者抛弃，无法获取收益？

**答（最终版，通俗表述）：**

支付和资金怎么管？
用户发需求时，先把承诺的最低服务费交到平台（现在用点数模拟，以后接真支付）。谈好最终价格后，不够的部分再补上。事情做完、验收通过，平台再把钱给服务者，同时从中留下大约5%作服务费。钱先过平台，不鼓励私下转账完成主交易。

撮合成功后，双方会不会抛开平台，平台赚不到钱？
事实上，熟人私下成交没法百分百挡住，美团和抖音直播刷礼物也一样。关键是让「走平台」更省心。平台里有托管、退款、纠纷处理、信用记录；走私下就没这些保护，下次也更难靠平台找到人。钱一开始就在平台里，结算时服务费已经扣掉，不是事后再找人要。

一句话：钱先进平台、办完再分；靠托管和站内保护留住交易，不指望完全没人私下成交。

## 7. 美团外卖如何保证抽成、怕不怕私下交易跳过平台？（对比参考）

**问：** 美团外卖是如何保证自己的抽成的，不怕私下交易跳过平台吗

**答：**

美团不怕私下交易到「抽成归零」，主要靠把「赚钱的那一步」锁在平台里，而不是靠口头禁止。

一是流量与履约依赖平台。商家要曝光、用户要配送，都靠美团的匹配、履约与评价。离了平台，多数店难稳定获客，骑手体系也接不住。二是结算在链上完成。用户当页支付，钱经平台再给商家，抽成在分账时扣，不是事后找人讨。三是违约有成本。绕开平台失去流量、评级与活动资格，被查还有处罚。四是未完全杜绝。熟人、固定客户仍可能私联，但主流程成本高、面不够大，伤不了主体收入。

对九木的启示：美团靠履约与分账留抽成；你们靠托管与结算内扣。都要让私下成交更不划算，而不是幻想零流失。

## 8. 国家允许钱先进平台吗？需要什么资格？办理哪些手续？

**问：** 需要了解国家政策和底线。国家允许钱先进平台吗？需要什么资格？办理哪些手续？

**答：**

先说底线：国家允许「交易资金先进入合规托管再结算」这种模式（电商、外卖、担保交易都这么干），但**不允许普通平台自建一套“平台自己收钱、自己记余额、自己给对方打款”而没有支付牌照**。后一种会被认定为无证从事支付业务或“二清”，属于监管红线。

换句话说：

- 允许的：钱先冻结、办完再分，但钱进**持牌支付机构或银行的合规账户**。
- 不允许的：普通互联网公司自己开个钱包，把用户真金白银存在公司账户里随便挪。

主体方面：本人已成立有限责任公司，并持有营业执照，具备接入企业支付商户的主体基础。九木现在用点数模拟，属于毕设/内测演示，不碰真资金，这一步是合规的。若要上线真支付，路线一般是下面两条，而不是自己去拿支付牌照。

路线一（现实首选）：以现有有限责任公司为主体，接入微信支付、支付宝等持牌机构的**担保交易 / 分账 / 平台收付通**能力。用户付钱进支付机构侧，验收完成后再分给服务者和平台，平台拿手续费，但**不碰客户备付金**。

路线二（门槛极高，一般不走）：自己申请成为非银行支付机构，拿人民银行《支付业务许可证》。按《非银行支付机构监督管理条例》等规定，设立门槛很高（例如注册资本通常至少1亿元量级、公司主体、风控与反洗钱制度、支付系统与人员等），新牌照极难拿，不适合毕设或当前阶段起步。已有执照不等于已有支付牌照，二者不能混为一谈。

手续层面（上线真支付时通常要办，不完全等同支付牌照）：

1. 公司主体与营业执照：已具备（有限责任公司 + 营业执照）。
2. ICP/网站备案、公安联网备案等互联网经营手续。
3. 以本公司与微信/支付宝等签订商户协议，做企业实名认证、对公账户、结算账户。
4. 开通相应的担保/分账产品，业务说明与风控材料按支付机构要求提交。
5. 涉及真实用户资金后，还要完善用户协议、隐私政策、交易日志留存、投诉与纠纷处理；反洗钱等义务按接入方与法规执行。

一句话答复导师：国家允许钱先进托管再结算，但不允许无牌平台自己存管用钱；我已有有限责任公司和营业执照，上线时以公司主体接入持牌支付机构分账，当前点数只是演示。

## 9. 聊天室是涉黄涉诈、违规行为频出的地方，如何应对？

**问：** 聊天室是个涉黄涉诈，违规行为频出的地方。

**答：**

聊天室确实是高风险区，涉黄、涉诈、引流、骚扰都容易在这里发生，不能假装没有这个问题。

九木的做法是：一、发布前拦截，需求标题、描述、昵称等先过敏感词和合规校验，违法内容不进公域。二、聊天内管控，私信和群聊支持举报、拉黑、投诉，可疑账号可冻结，严重违规清退并留日志。三、场景收窄，优先在需求圈内沟通，减少全网陌生人裸聊，两段式接单和限时沟通，降低长期纠缠。四、交易不脱管，引导站内完成托管与验收，减少加微信私下聊式引流。五、对未成年人，注册年龄门槛、交易限额，校园类需求鼓励落在家长圈等同类场景。

一句话：聊天室风险客观存在，平台不靠不管，靠发布前审核、举报处置、圈内对接和资金托管，把聊天锁在可追溯、可处罚的业务链路里。
