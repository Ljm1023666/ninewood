## 二、申请材料清单（待准备）

### 2.1 主体证件

- [ ] 营业执照原件扫描件（彩色，清晰）
- [ ] 法人身份证正反面扫描件
- [ ] 如果主体有变更：ICP 备案主体变更证明

### 2.2 域名证件

- [ ] 域名证书（阿里云 / 腾讯云 / Cloudflare 均可申请）
- [ ] 域名实名认证截图（所有者 = 公司主体）

### 2.3 服务器证明

- [ ] 阿里云 ECS 公网 IP
- [ ] 阿里云服务器购买订单 / 备案服务号

### 2.4 负责人证件

- [ ] 网站负责人身份证（可为法人本人 / 或被授权人）
- [ ] 如果非法人：授权委托书 + 被授权人身份证

### 2.5 前置审批（如涉及）

九木内测期为威客/兼职撮合平台，**不属于以下需前置审批的范围**：

- 新闻、出版、教育、医疗、药品、医疗器械、文化、广播电影电视节目
- 金融、证券、期货、保险
- 药品交易、危险化学品、烟花爆竹

**如公测期涉及以下功能需补充前置审批**：

- 直播 / 短视频 → 网络文化经营许可证
- 支付 / 交易 → ICP 经营许可证（EDI 证）
- 互联网新闻信息服务 → 新闻信息服务许可证
- 药品/医疗器械 → 药品监督管理部门批准
