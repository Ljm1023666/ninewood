# 个人信息影响评估（PIA）— 内测版 v0.1

依据：《个人信息保护法》§55-§56

> 内测期采用简化版 PIA；公测前由法务/DPO 完整化。

## 一、处理活动概要

| 项 | 内容 |
|---|---|
| 处理者 | 乌鲁木齐往昔科技有限公司（备案主体） |
| 涉及产品 | 九木（Ninewood）桌面端 Web / Electron |
| 阶段 | 内测（受邀用户，< 200 人） |
| 周期 | 2026-06 起，预计 3 个月 |

## 二、处理的个人信息种类

| 类别 | 字段 | 合法性基础 | 用户权利保障 |
|---|---|---|---|
| 身份识别 | 手机号、出生日期、昵称 | 同意 + 合同必要 | 查阅、更正、删除 |
| 设备信息 | IP、UA、大致属地 | 同意 + 法定 | 撤回 |
| 行为 | 需求、订单、消息 | 合同必要 | 查阅、复制、删除 |
| AI 对话 | 用户输入 + AI 回复 | 同意（AI 服务协议） | 删除（保留 90 天） |
| 资金模拟 | 模拟点数 | 合同必要（模拟） | 查阅 |

## 三、风险评估矩阵

| 风险 | 可能性 | 影响 | 缓解措施 |
|---|---|---|---|
| 手机号泄露 | 中 | 高 | 加密存储 + 访问审计 + 最小权限 |
| 14 岁以下误注册 | 低 | 高 | 服务端强制校验（已实现）+ 出生日期必填 |
| AI 输出违规 | 中 | 中 | 内容安全过滤（已实现开关）+ 用户举报 |
| 对话被用于训练 | 低 | 中 | 内测期默认不训练；用户协议明确 |
| 日志泄露 | 低 | 中 | 内测期 console.log 即可；公测前接入文件日志 + 6 个月留存 |
| 密码泄露 | 中 | 高 | bcrypt rounds=12 + 强制改密（公测前） |
| JWT 泄露 | 中 | 高 | 7 天有效期；公测前改 HttpOnly Cookie |

## 四、用户权利保障

| 权利 | 内测期实现 | 公测前增强 |
|---|---|---|
| 知情权 | 注册前主动勾选《隐私政策》《AI 服务协议》《内测知情同意书》 | 律师审阅 + 弹窗版本管理 |
| 决定权 | 可拒绝；不勾选无法注册 | — |
| 查阅/复制 | "我的数据"页导出 JSON | 完整导出所有数据 |
| 更正 | 资料页可改手机号/昵称/头像 | — |
| 删除 | 局部删除（订单等不可删） | 完整注销流程 + 30 天反悔期 |
| 撤回同意 | 设置页提供 | 详细撤回项 + 影响说明 |
| 解释权 | AI 回答附"AI 生成"标识 | 增强决策可解释性 |

## 五、跨主体处理

- **腾讯云 SMS**：发送验证码；仅获得手机号 + 验证码内容
- **DeepSeek / Qwen**：AI 推理；获得用户输入的对话内容
- **hCaptcha**：人机验证；仅获得前端 token
- **Sentry**（境外）：异常日志；公测前替换为境内方案

## 六、剩余风险与遗留

1. Sentry 仍为境外 → 公测前必须替换
2. 14-18 岁监护人同意为承诺制 → 公测前补完整流程
3. 模拟点数无真实资金 → 商业化前需重新设计
4. 无等保测评 → 公测前完成等保 2.0 二级
