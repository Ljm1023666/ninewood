# 数据分类分级表（内测版 v0.1）

依据：《数据安全法》§21、《个人信息保护法》§4

> 本文件为内测期内部数据分类参考；公测前需经法务/DPO 审阅后定稿。
> 不在此文件内列出具体敏感字段的明文示例，避免误传。

## 一、数据分级框架

| 级别 | 名称 | 范围 | 保护要求 | 内测期示例 |
|---|---|---|---|---|
| **L1** | 公开数据 | 用户主动公开的展示信息 | 公开 | 昵称、头像、需求标题、需求描述（脱敏后） |
| **L2** | 内部数据 | 仅平台内可见 | 加密传输 + 访问控制 | 手机号、订单详情、需求完整信息 |
| **L3** | 敏感数据 | 可识别个人身份 | 加密存储 + 单独同意 + 审计日志 | 身份证号、银行卡、人脸、位置 |
| **L4** | 高敏数据 | 一旦泄露造成严重后果 | 强加密 + 最小权限 + 定期轮转 | 密码哈希、JWT 签名密钥、支付凭证 |

## 二、九木平台数据分类明细（内测期）

### 2.1 用户身份数据（L2-L3）

- L2: 手机号、昵称、头像 URL、城市代码、注册时间
- L3: 出生日期（合规校验用）、IP 属地（仅省/市）、身份证号（**当前未采集**；公测前再决定是否引入）

### 2.2 行为数据（L1-L2）

- L1: 公开需求、评价
- L2: 私聊内容、订单状态、需求草稿、AI 对话历史

### 2.3 资金模拟数据（L2）

> 内测期所有点数/奖励均为模拟，无真实资金流转。

- L2: 用户点数余额、激励池余额、模拟交易记录

### 2.4 内容安全数据（L2）

- L2: 举报记录、内容审核日志、关键词命中日志

### 2.5 系统凭证（L4）

- L4: JWT 签名密钥、bcrypt 密码哈希、API Key、数据库连接串

## 三、流转与共享清单

| 数据 | 流向 | 接收方 | 依据 |
|---|---|---|---|
| 手机号 | 用户 → 平台 | 自有 | 注册必需 |
| 对话内容 | 用户 → 平台 → LLM | DeepSeek/Qwen（境内） | 用户主动提交；用户协议 + AI 服务协议 |
| 异常日志 | 平台 → Sentry | Sentry（境外） | 公测前必须切换为境内 Sentry 替代（如阿里云 SLS） |
| 验证码 | 平台 → 用户手机 | 腾讯云 SMS | 注册必需；当前仅内测用 |

## 四、重要数据识别

经评估，**九木平台内测期不涉及"重要数据"**（《数据安全法》§21 列举的：人口健康、关键基础设施、地理信息等）。如未来接入以下功能，需重新评估：

- 大量身份证 / 人脸数据 → 触发重要数据
- 跨境数据传输 → 触发重要数据评估 + 出境安全评估
- 接入关键信息基础设施 → 触发重要数据

## 五、出境评估

内测期所有用户与系统数据均存储在**境内阿里云 ECS**。LLM 调用仅使用**境内端点**（DeepSeek / Qwen）。**不存在数据出境场景**。Sentry 仍为境外（公测前替换）。
